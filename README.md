# AI 戏精导演 · 奶油绿多人片场 V0.7

新版入口是 `index.html`，不需要安装前端依赖。界面已按选定的第 2 版视觉稿实现，使用奶油白、浅绿、橙色按钮及 3D 动物素材。用户提供的原文件保留在原位置。

请将 `index.html`、`style.css` 和 `assets` 文件夹放在同一目录，发布时一并上传。`assets/ASSETS.md` 保存了素材文件说明和生成提示词。

## 启动

在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，然后打开 http://127.0.0.1:8765/ 。

真实摄像头需要 localhost 或 HTTPS。手机使用时请部署到 HTTPS 站点。手机直接打开电脑的局域网 HTTP 地址通常无法申请摄像头。首次启动需要访问 jsDelivr 或 unpkg，以及 Google 模型存储地址。

## 使用

- 待机画面及其三张角色卡均为示意，实际入镜人数为 0。“播放加戏示例”播放三位虚拟演员的示意动画，不调用摄像头。
- “开启摄像头”加载模型并预览卡通遮脸。“开始加戏”在此基础上启用动作剧情。
- 最多分配 4 个演员席位。每位演员独立检测扶额、双手抱头和转头，并单独控制重复触发。多人同时做动作时，字幕间隔至少 1.7 秒；持续动作会依次触发，间隔内结束的短动作可能不显示。
- 点击演员卡，再点击右侧角色，可切换狐狸、兔子、小熊或青蛙。待机示意角色和实时遮脸均使用 3D 素材。加戏强度调整三档文本，剧情音效可关闭。
- 关闭本场、切换到后台和摄像头断开都会停止摄像头。互动记录保留到刷新页面，最多显示最近 40 条。

## 实现与边界

FaceLandmarker 最多检测 8 张脸，PoseLandmarker 最多检测 4 个身体。两组结果按头部位置一对一配对。演员编号按相邻帧的位置和尺寸匹配，短暂离开保留 1.2 秒。它是位置跟踪，不识别个人身份。交叉走动、长时间遮挡或离镜后返回可能交换编号或分配新编号。

原始 video 元素始终隐藏。每次取同一张画布快照做识别与合成，卡通头像覆盖检测到的脸。脸部检测缺失时，已检测到的身体头部可用作覆盖位置。整帧没有头部位置时，显示模糊画面。超过演员席位的已检测头部也会加匿名卡通遮罩。

这是卡通头像覆盖，不是生成式换脸。漏检的人脸可能在其他玩家已被检测到时露出，不能当作严格的匿名化工具。快速移动、侧脸、遮挡、低照度和远距离小脸需要真人测试。超过 4 人不在游戏支持范围内。

识别在浏览器本机执行，代码不录制、不上传视频、不申请麦克风。外部网络请求用于下载运行库、WASM 和模型。两个模型每帧同步推理，输入上限由摄像头协商，推理间隔至少 100 ms；实际帧率取决于设备。脸部模型加载失败时关闭摄像头并报告错误。姿态模型失败时保留卡通覆盖和转头检测。

## 检查

运行 `node --test tests/tracking.test.cjs` 检查模型输出顺序变化、角色保持、离镜超时、额外头部遮罩、身体与脸部配对、单手遮挡、多人独立触发和取消摄像头启动。

打开 `/tests/model-smoke.html` 下载正式模型并验证多人配置和空白帧推理。这个页面不申请摄像头。它能确认模型接口可运行，真人检测效果需另外检查。

真人验收建议用 2–4 人站在同一平面，依次入镜、切换角色、同时做不同动作、交叉移动、扶额遮脸、离镜再返回，再检查关闭按钮及后台断开。记录实际帧率和误触发，不能由示意动画推断真实识别效果。

API 依据见 [Face Landmarker Web](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js) 和 [Pose Landmarker Web](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js)。
