# 橙帽女生建模参考包 v1

本包完成橙帽女生的造型参考设计。图片由内置 imagegen 生成，属于二维参考图。包内未包含可运行的三维网格、骨骼或 GLB 文件，也未替换网页中的程序化模型。

先以原始确认图确定人物气质和材质，再用头部视图确定结构。全身图补充衣服与站姿。表情图用于检查面部变化，不用于重新定义基础脸型。视图标注 LEFT / RIGHT 表示画面方向，不能直接用作程序中左右眼的解剖命名。

## 固定造型

- 橙色帽檐和后帽身，奶油白色前帽片，无标志。背面采用可调节帽带。
- 栗棕色肩长卷发，按大块发束塑造体积，再补细节。保留侧面和后脑体积。
- 棕色眼睛，柔和脸颊、小鼻子、圆润下巴，金色圆环耳饰。
- 鼠尾草绿色连帽衫，奶油白抽绳，宽松袖口和下摆。
- 奶油色绒面宽腿长裤，裤脚自然垂落，不做弹力收口。
- 橙白运动鞋，无品牌标志。

背面帽带与不可见发束是本次补充设计。AI 图片中的发丝位置、眼睛细节和帽片比例可能存在视角差异。建模时统一成同一个三维结构，不能逐张分别照搬。图中辅助线用于对齐参考，不是经过测量的工程尺寸。

## 建模优先级

1. 先做头部、头发、帽子、耳饰、颈部。摄像头遮脸优先验证这一部分。
2. 先检查基础脸型的正面、两个四分之三侧面、两个侧面和背面。保证转动时鼻子、下巴、耳朵、帽檐和后脑有连续体积。
3. 再做眼睑、口腔和表情变形。左右闭眼分别控制，张嘴和微笑分别控制。张嘴参考图带轻微笑意，制作 jawOpen 时要保持眉毛和嘴角尽量自然。
4. 通过头部预览后，再制作身体。当前项目保留真实身体动作，第一阶段不需要全身替身。

## 三维资产交付建议

- 保存可编辑的建模源文件，并导出一个含材质与贴图的 GLB。
- 面部、眼球、头发、帽子、耳饰便于独立调整。眼球和口腔需要真实几何体，侧面不能露出空洞。
- 头部使用明确且稳定的旋转中心。记录朝向、单位、坐标系和尺寸，接入时以同一基准校准。
- 表情至少提供独立的 eyeBlinkLeft、eyeBlinkRight、jawOpen。若增加微笑、抬眉等表情，附上名称和权重说明。
- 帽子和头发随头部转动。避免眼睑闭合时穿透眼球，避免张嘴时嘴唇拉裂或牙齿随下唇一起变形。
- 使用适合实时预览的发束和材质。图中的绒毛和头发细节应转化为可控的几何体、法线或贴图，不能以参考图的静态渲染效果作为移动端性能保证。

以上为后续制作要求，未代表本包已经生成对应网格或表情。

## 接入网页后的验收

- 使用模型实际渲染截图与原图并排比较。相同姿势和接近的光照下检查脸型、眼睛、卷发和帽子。
- 覆盖左右转头、抬头、低头、歪头、独立眨眼和张嘴。检查遮挡、穿透、头部旋转中心与跟踪延迟。
- 在目标手机上依次测试单人、双人、四人。记录识别耗时、渲染帧率、温升和丢失后重新识别的表现，再决定模型精度与材质数量。
- 先完成一个角色的模型和摄像头测试，再扩展另外三个人物。
